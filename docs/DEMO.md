# 5 分钟课程验收演示

1. **0:00–0:40 架构**：展示双 Eureka、Gateway 和五个 Java 服务均为 UP，说明 Ribbon、Feign、Hystrix。
2. **0:40–1:20 登录与人员**：管理员登录，展示用户、人员、车辆/人脸信息和权限隔离。
3. **1:20–2:30 预约审批**：访客创建预约，被访人审核，保卫处最终审批并签发二维码。
4. **2:30–3:30 通行闭环**：门岗扫码核验，展示通行记录、次数和有效期控制。
5. **3:30–4:20 异常闭环**：演示拒绝/高风险事件、异常列表、黑名单与门岗处置。
6. **4:20–5:00 容错与数据**：展示 Ribbon 实例与 Hystrix 指标，打开 31 表字典和 3NF 说明收尾。

演示前按 [RUNBOOK](RUNBOOK.md) 启动，并确认两个 Eureka 节点都能看到全部 UP 实例。不要现场执行初始化、seed、生产 DDL 或删除操作。若外部短信不可用，应明确说明未接正式供应商；不要把快捷登录描述为生产认证。
